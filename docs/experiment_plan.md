# 实验推进计划

## 阶段一：数据和探索性分析

输出数据质量统计、借还需求时间曲线、星期 × 时间段热力图、站点需求排名和站点空间分布图。完成标准是能够确认工作日、周末、早晚高峰的需求差异。

## 阶段二：基线模型

实现历史平均法和前一天同一时刻预测，输出固定测试集上的 MAE、RMSE、WMAPE。

## 阶段三：Transformer

实现滑动窗口数据集、Transformer Encoder、训练曲线、最优模型权重和测试集预测结果。

## 阶段四：比较和误差分析

输出模型比较表、真实值与预测值曲线、各站点 MAE 空间图、高峰/平峰误差对比和误差原因分析。

## 阶段五：可选增强

基础模型和报告主体完成后，再尝试添加天气特征、站点空间注意力、未来两个时间步预测，并用多个随机种子报告均值和标准差。
