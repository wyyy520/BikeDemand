# 10 万条样本数据检查

## 获取结果

- API：深圳市政府数据开放平台“共享单车企业每日订单表”；
- 接口声明总量：244,638,540 条；
- 请求页数：10 页；
- 每页请求量：10,000 条；
- 接口接收记录：100,000 条；
- 去重后写入 SQLite：99,967 条；
- 数据库：`data/raw/orders_sample_100k.sqlite`。

## 字段检查

返回字段与后续任务匹配：

```text
START_TIME, END_TIME,
START_LAT, START_LNG, END_LAT, END_LNG,
USER_ID, COM_ID
```

起点和终点坐标、开始和结束时间均可用于空间网格聚合。`USER_ID` 已脱敏，`COM_ID` 在样本中为空，因此二者不作为第一版模型输入。

## 样本质量统计

| 检查项 | 结果 |
|---|---:|
| 时间缺失 | 0 |
| 坐标缺失 | 0 |
| `END_TIME < START_TIME` | 0 |
| 起点坐标超出深圳近似范围 | 0 |
| 终点坐标超出深圳近似范围 | 13 |
| 骑行时长超过 24 小时 | 3 |

| 起终点完全相同 | 38 |

深圳近似范围检查使用纬度 `22.4～22.9`、经度 `113.7～114.7`，仅用于发现明显异常，正式清洗时应根据数据分布和地图范围确定规则。

## 重要限制

这 10 万条记录不是连续日期样本：开始时间覆盖 2017-04-03 至 2020-08-22，共 1182 个日期。它适合验证接口、字段、异常值处理和空间网格代码，不适合直接训练最终时序 Transformer。

正式实验需要继续获取连续日期范围，例如连续 4～8 周，并在报告中按时间顺序划分训练、验证和测试集。
