\section{任务概述}
本作业基于深圳市政府数据开放平台的共享单车企业每日订单表，对2021年1月1日至2月2日期间约300万条订单记录进行了时空需求分析与短时预测建模。将城市范围划分为 $0.01^\circ \times 0.01^\circ$ 的网格，选取订单量最大的30个网格，按30分钟粒度聚合借车量与还车量，构建 $[T, 60]$ 维的需求时序矩阵。预测目标为未来30分钟各网格的借还车量。

全部代码（数据爬取、清洗、聚合、模型训练、评估）已上传至GitHub仓库：\url{https://github.com/wyyy520/BikeDemand}，主要源代码见文末附录。

\subsection{空间分布特征}
30个高需求网格集中在深圳市中心城区，覆盖CBD、大型居住区和轨道交通枢纽周边。借车与还车量在这些网格间的分布相对均衡，但个别网格的峰值需求显著高于其他网格，反映出职住通勤的不对称流动特征。

\section{预测建模}

\subsection{方法设计}
采用Transformer编码器结构，输入过去24小时（48个30分钟步）的借还车需求及时间周期特征（日内正弦/余弦、周内正弦/余弦、周末标记、高峰标记），输出未来30分钟的60维需求向量。

考虑到previous-day基线对日周期惯性的强捕捉能力，模型采用\textbf{残差学习}策略：预测目标不是绝对需求，而是目标时刻需求减去前一日同时刻需求的修正量。评估时将预测残差加回基线再还原为订单数。这一设计使模型直接学习"何时偏离昨日模式"，避免了从头学习周期性。

\subsection{特征构造方法}
模型输入由三部分特征拼接而成：
\begin{enumerate}
\item \textbf{需求特征}：过去24小时（48个30分钟步）30个网格的借车量与还车量，共 $48 \times 60 = 2880$ 维。这是模型的主要信号来源。
\item \textbf{目标时刻滞后特征}：前一日同时刻（lag=48步）的借还车量，共60维。该特征为previous-day基线提供了显式通道，使残差学习成为可能。
\item \textbf{时间周期特征}：对预测目标时刻构造以下5个特征：
  \begin{itemize}
  \item 日内正弦 $\sin(2\pi t / 48)$ 与余弦 $\cos(2\pi t / 48)$，其中 $t$ 为30分钟步索引；
  \item 周内正弦 $\sin(2\pi d / 7)$ 与余弦 $\cos(2\pi d / 7)$，其中 $d$ 为星期索引；
  \item 周末二值标记（周六、周日为1，其余为0）。
  \end{itemize}
\end{enumerate}
所有需求特征在训练集上做z-score标准化，避免数据泄露。模型的输出为未来30分钟60维（借车+还车各30网格）需求向量。

\subsection{数据划分}
发现数据分布不均匀后，将划分方式从按比例改为\textbf{按日期划分}：
\begin{itemize}
\item 训练集：2021-01-30 13:00 至 2021-01-31 20:00（高量数据段）
\item 验证集：2021-01-31 20:00 至 2021-02-01 04:00
\item 测试集：2021-02-01 04:00 至 2021-02-02 14:00
\end{itemize}

\section{误差空间分布分析}

对Transformer在测试集上各网格的MAE进行分解（图\ref{fig:spatial}），发现误差在空间上分布不均：部分网格MAE显著高于平均，主要集中在高峰时段订单量最大的网格；而需求较少的网格误差较小。

\begin{figure}[H]
\centering
\includegraphics[width=0.95\textwidth]{figs/spatial_error.pdf}
\caption{Transformer测试集各网格MAE分布（左：借车，右：还车）}
\label{fig:spatial}
\end{figure}

误差在空间上呈现"高需求--高误差"的正相关关系，原因包括：
\begin{enumerate}
\item \textbf{需求绝对量大}：高峰期单网格30分钟订单可达数千辆，即使相对误差仅10\%，绝对MAE也远高于低需求网格；
\item \textbf{需求波动性更强}：高需求网格对突发事件（天气变化、交通管制、周边活动）更敏感，昨日同期基线难以捕捉这类偏离；
\item \textbf{数据量不足}：训练段仅约31小时高量数据，模型无法充分学习不同网格在不同时段的差异化模式，只能学到全局性的周期修正。
\end{enumerate}

\section{原因总结与讨论}

\subsection{previous-day基线为何难以超越}
previous-day基线本质上是把"昨日同时刻真实需求"作为预测值，它免费获取了48步连续的真实观测信号，对具有强日周期惯性的通勤型出行需求捕捉能力极强。在本数据集上，测试集仅约2天且紧邻训练段，日间相关性极高，导致该基线接近"抄答案"的效果。

Transformer残差模型已将previous-day作为硬编码起点，模型只学习修正量，但在数据量有限（有效高量训练数据约31小时）的条件下，能学到的修正模式非常有限，最终MAE仅比基线高0.6（61.0 vs 60.4），接近但未能超越。

\subsection{深度模型的适用条件}
结合实验结果与相关文献，Transformer等深度模型要体现出对简单基线的明显优势，通常需要：
\begin{itemize}
\item \textbf{更长时间跨度}的数据（数月以上），以学习不同周、不同节假日、不同天气下的多样化模式；
\item \textbf{测试集与训练集存在真实分布差异}，而非相邻时段的高相关；
\item \textbf{额外特征}（天气、POI、空间拓扑等），这些是previous-day基线完全无法利用的信号。
\end{itemize}

\subsection{本次实验的局限}
\begin{itemize}
\item 数据覆盖仅32天，且前29天几乎无有效订单，时间分布严重偏斜；
\item 高量数据仅约4天，测试集进一步缩减至约1.4天，样本量过小；
\item 未融合天气、POI等外部数据；
\item 空间维度上30个网格独立预测，空间注意力模块虽已实现，但因测试集过短未能体现优势。
\end{itemize}

\section{总结}
本作业完成了共享单车需求的时空特征分析、Transformer残差预测模型的构建与训练，并与historical\_mean、previous-day、LSTM等基线进行了系统对比。主要结论：
\begin{enumerate}
\item 共享单车需求具有明显的日内双峰周期和工作日/周末差异，previous-day基线因此表现很强；
\item 残差建模使Transformer从previous-day水平出发学习修正量，有效提升了训练效率与最终精度；
\item 在数据覆盖短、时段单一的不利条件下，Transformer（MAE=61.0）接近previous-day（60.4）而未超越，反映出深度模型对数据量的依赖；
\item 误差空间分布呈"高需求--高误差"特征，主要由需求绝对量大、波动性强和数据不足共同造成。
\end{enumerate}

若后续继续改进，建议优先扩大数据时间跨度、融合天气与POI特征，并在更充分的测试条件下重新评估空间注意力的作用。
